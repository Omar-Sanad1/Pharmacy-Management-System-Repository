# Pharmacy-Management-System-Repository
Pharmacy Management System API built with ASP.Net Core Web API &amp; Onion Architecture.

## Author
**Omar Mahmoud Sanad**


## Technologies
- ASP .Net Core Web API
- Entity Framework Core (Code First)
- SQL Server
- Linq(Language Integrated Query)
- JWT Authentication
- AutoMapper
- BCrypt For Password Hashing
- Swagger


## Features
- Login & Registeration
- Customer Management
- Employee & Doctor Management
- Medicine & Batch Management
- JWT Authentication
- Filtering & Searching
- Pagination
- Sorting
- Data Seeding
- Fluent API Configurations

## Architecture
- Onion Architecture :
                      - Domain Layer (Core)
                      - Repository Layer
                      - Service Layer
                      - API Layer
  -DTOs

## How To Run
1. Clone Repository
2. Update Connection String
3. Run Migration
4. Run Project
